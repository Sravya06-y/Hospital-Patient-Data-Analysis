# Hospital Patient Data Analysis and Decision Support System

## Project Overview

The Hospital Patient Data Analysis and Decision Support System is a Python-based project that analyzes hospital patient data. It helps identify patient risk levels, understand hospital trends, and generate review suggestions based on triage levels.

## Objectives

* Clean and preprocess hospital patient data.
* Identify missing values and duplicate records.
* Analyze patient information using graphs.
* Understand readmission rates and hospital stay durations.
* Generate decision-support suggestions based on triage levels.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab
* GitHub

## Project Workflow

1. Dataset Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Patient Decision Support

## Visualizations

The project includes the following graphs:

* Triage Level Distribution
* Readmission Rate by Age Group
* Stay Length by Diagnosis

## Decision Support System

The system generates review suggestions based on triage levels:

* Triage Levels 1 and 2 – Immediate Review
* Triage Level 3 – Priority Review
* Triage Levels 4 and 5 – Routine Review

These suggestions are rule-based and are intended to support analysis, not replace medical decisions.
